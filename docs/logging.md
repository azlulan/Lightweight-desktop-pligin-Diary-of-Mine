# 本地日志约定

## 文件位置

日志根目录来自设置页。默认 Debug 路径为：

```text
%LOCALAPPDATA%\DiaryOfMine.Dev\userdata\logs
```

Release 使用 `DiaryOfMine`，不带 `.Dev`。实际文件按本地日期归档：

```text
日志根目录\2026-09-10\DiaryOfMine.txt
```

文件采用 UTF-8 纯文本，可以直接用 Windows 记事本打开。日志目录更改后，后续记录写入新目录；已有文件不会自动移动。

## 记录格式

每个关键操作产生一条“输入”和一条“输出”，两者使用相同的 `id`：

```text
2026-09-10 09:30:12.105 +08:00 | 输入 | event=settings.save | id=2f7d909811f1
2026-09-10 09:30:12.112 +08:00 | 输出 | event=settings.save | id=2f7d909811f1 | result=success
```

若操作异常，输出记录包含异常类型、HRESULT 和发生方法，不写异常消息：

```text
2026-09-10 09:31:08.440 +08:00 | 输出 | event=settings.save | id=be420fd68c91 | result=failure | error=System.UnauthorizedAccessException | hresult=0x80070005 | site=Example.Type.Method
```

`result=incomplete` 表示代码离开了操作范围，却没有明确记录成功或失败，应作为代码闭合问题排查。`cancelled` 表示用户主动取消文件夹选择，不属于错误。

## 当前覆盖范围

- 应用启动、退出请求和停止
- 设置加载、保存及运行期应用
- 缓存目录和日志目录选择
- 日志输出目录切换
- 左侧导航切换
- 日程范围读取、创建、修改和删除
- 日程录入窗口与日期详情窗口
- 主窗口关闭隐藏、Esc 隐藏和恢复
- 自动进入悬浮休眠
- 悬浮窗位置保存
- UI 线程未处理异常
- 进程级未处理异常
- 未观察的异步任务异常

后续业务用例必须通过 `IAppLogger.BeginOperation` 建立操作范围，并在成功时调用 `Complete`、失败时调用 `Fail`。日志实现会在操作对象未闭合时自动写入 `incomplete`。

## 隐私与故障边界

事件名和结果只能使用受限标识符。禁止记录日记标题、正文、标签、密码、密钥、用户选择的目录、异常消息、连接字符串或任意输入内容。异常只保留类型、错误码和方法位置。

日志采用逐条写入并刷新到磁盘，方便崩溃后保留最近记录。写入允许记事本同时读取。磁盘已满、目录失去权限或文件被占用时，日志模块静默停止该条写入，不能递归记录自身错误，也不能把日志回退到其他未经用户选择的位置。
