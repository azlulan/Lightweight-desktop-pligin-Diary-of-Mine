## 2. 不变量清单

### 数据

- Key 不跨开始日午夜；默认结束是真实持久化值，不是只在 UI 推断。
- Class、Key、Idea 可使用完成状态；Inspiration 必须规范为未完成。完成项不得进入提醒结果。
- Idea/Inspiration 没有 EndsAt；TaskBatch 只属于 Key。
- Task 批次日期合法、星期非空、结束分钟晚于开始分钟。
- 快捷链接仅属于 Class/Key/Idea；支持文件与文件夹，每项最多 32 条、路径不重复且最多置顶一条。链接失效时保留地址和目录类型，移除绑定不能删除原内容。
- 每日期最多一篇日记；日记退出保存不得静默丢内容。
- 工作目标名最多 4 个文本元素；只有一个活动 Session；Session 最长 24h；中断属于且位于 Session。
- 文件解析失败保留原文件，不自动重置为空。

### 交互

- 月历边界拖动半小时精度；编辑器和详情边界为分钟精度。
- 色块边界只有从手柄按下才修改；内部拖动用于甩飞删除（工作 Session 例外：不可删除）。
- Class/Key 在详情共用并发容量与 Shift+滚轮偏移。
- 完成的 Class/Key 在两套日程排序中始终置底、统一灰化并给名称加删除线；完成 Class 不显示倒计时。
- Task 双击整批编辑，单次拖动/甩飞只改 occurrence。
- Task occurrence 的快捷链接新增、置顶、移除和重新定位只改当前记录；整批重排只按仍存在的同日期保留，不复制到其他 occurrence。
- `Shift + 左键` 完成切换同样只保存被点击记录；Task occurrence 不得调用整批替换。
- 月历与详情撤销栈独立。
- 详情只有一个窗口，前后日期复用。
- 点击主窗口或其他程序不会自动提交或关闭编辑窗；确认、取消和 Esc 仍由编辑窗口自己处理。
- 单行表单 Enter 按可见且启用的字段顺序推进，最后确认；日记编辑器不接入此规则，正文 Enter 必须继续正常换行。按钮获得焦点时使用原生 Enter，不得被通用处理重复触发。
- 自动悬浮开启时，主窗口失焦、最小化和关闭都进入悬浮；关闭设置时才保留任务栏最小化和关闭到托盘语义。“回到月历”不是窗口消失事件。

### 视觉

- 延续全局 WPF 样式、柔和浅色与圆角；不要为单页引入完全不同的配色语言。
- 有方框的按钮统一圆角；图标在同一工具栏视觉重量相当。
- Class 色板比 Key 浅，Key 圆点/色块更深；颜色数据仍使用逻辑槽。
- 时间标签必须按可用宽度降精度，最后一个标签不与倒数第二个重叠。
- 每次 Render 前清空动态容器/标记集合，避免缩放或 resize 后叠加旧 `+N` 提示。

### 隐私和发布

- 不把 `%LOCALAPPDATA%\DiaryOfMine*`、自定义缓存、日志、用户图片、测试 JSON 放入发布目录。
- Debug 和 Release 根目录保持隔离。
- 卸载默认不删除个人数据；若未来改变必须单独确认并在 UI 明示。
- 未重打包时，不得把源码修复写成“安装包已修复”。

## 3. 建议修改顺序

1. 阅读本目录总览和对应专题；用 `rg` 搜字段/事件的所有引用。
2. 确认需求影响的是单条 occurrence、Task 批次还是全部数据。
3. 如涉及数据，先更新 Domain 验证和 Application Service 规范化。
4. 更新仓储/schema（若需要），设计旧文件迁移和失败回退。
5. 更新 ViewModel 命令/历史，再更新 XAML/code-behind。
6. 检查 `App.xaml.cs` 的跨页面刷新、唯一窗口、缓存切换和提醒联动。
7. 更新本目录文档与根 README 更新日志；标明是否打包/验收。
8. 做必要编译检查。除非用户要求，不生成安装包、不启动大规模模拟测试。

## 4. 按模块最小回归点

### 日程/月历

- 新建四类内容与 Task，重启后仍在。
- Key 未填结束点、23 点后创建、手输非法时间。
- Class 跨月/单日/无结束；拖两端后倒计时和优先级更新。
- Class/Key 勾选与取消“已经完成”后，颜色、删除线、倒计时、排序和提醒规划同步恢复/更新。
- 月历 Class/Key、详情 Class/Key 的 `Shift + 左键` 均可往返切换；点击端点时只要按着 Shift 也应优先切换完成状态。
- 点击日期时 Class/Key 文字切换；普通 Key 与 Task Key 分列。
- Shift+滚轮上下提示随 offset、窗口变化和重绘正确消失/出现。
- 甩飞、undo、redo；Task occurrence 与整批语义。

### 单日详情

- 一行/两行切换、最小和最大窗口、不同缩放；11/23/24 点等标签无缺失重叠。
- 中键平移/恢复、滚轮围绕鼠标缩放、今天当前时间线。
- 共享并发容量与优先级；resize 后无旧提示残留。
- 跨行文本不重名，时间仍是完整事项起止；Key 带 `*`。
- 起止手柄分钟编辑、中间日无手柄、单次 Task 修改。
- 前/后一天复用同窗，跨日期 undo，回到月历不最小化。
- Idea 勾选/编辑/删除，灵感无日期选择但显示创建时间，+日记日期正确。
- Class/Key/Idea 编辑器可混合拖入及分别多选文件/文件夹；重复/失效输入被忽略，缓存路径提示正确；详情悬停窗能打开、置顶、移除、按类型重新定位，且全程只变更地址。
- 普通日程各 Kind 逐项按 Enter，隐藏时间/结束项被跳过；最后一项只提交一次。灵感 Enter 换行、Ctrl+Enter 确认；底部确认区默认可见。日记正文 Enter 仅换行。

### 日记

- 搜索栏在小窗口仍可点；标题/正文/日期数字可筛选。
- 新建、改标题后外层卡片刷新；文本粘贴、图片插入/粘贴按块换行。
- 手动保存、Esc、关闭按钮、程序退出保存；保存错误时不关闭。
- 切换缓存目录后读取目标数据或复制当前数据，不能混合覆盖。

### 工作模式

- 默认/自定义目标、新增和重命名；Add 不出现颜色选择。
- 主页面与悬浮面板都能开始录制；录制提示同步。
- Finish、活动/手动中断、跨午夜和 24h 自动封顶。
- 手工中断窗口默认打开以及缩到最小高度时，底部“取消 / 添加中断”必须始终可见；表单内容过高时仅滚动表单区。
- 工作目标新增/重命名可按 Enter 保存；中断表单可依次 Enter 前进并确认；录制目标面板打开即聚焦首项且 Enter 可选中。
- 色块只改目标不可删除；两行绘制正确。
- 今日/累计与两种排序，跨午夜今日时长裁剪。

### 窗口/Windows

- Esc 子窗关闭，再次 Esc 进入悬浮；展开热键单键/双键。
- 开启设置且没有受保护编辑窗时，点击程序外、主窗口最小化或关闭都会显示悬浮窗。
- 编辑器、详情窗、文件选择和资源管理器拖放期间不自动悬浮，也不自动提交或关闭编辑内容；误最小化/关闭会恢复编辑窗。
- 关闭设置时，任务栏最小化/还原保持 Windows 语义，手动关闭主窗口隐藏到托盘且后台继续运行。
- 开机自启参数 `--startup` 后进入悬浮；单实例行为。
- 安装器相关仅在明确打包任务时执行真实安装/卸载验收。

## 5. 已知技术债/谨慎点

- `HomePageView.xaml.cs` 和 `CalendarDayDetailWindow.xaml.cs` 较大，绘制、状态机和窗口动作集中；重构时应先写行为对照，避免拆分导致手势顺序变化。
- `LinksPage*` 命名仍为历史“链接”，不要据名字删除或恢复旧链接页面。
- SQLite、vault、backup 路径及部分早期接口仍存在，但当前主流程未接入；不要在文档中把预留结构称为已实现。
- JSON 明文且日记图片 Base64 可能使文件变大；未来加密/数据库化应作为独立迁移项目。
- Windows 任务栏固定受系统版本/策略影响，创建快捷方式与调用 Pin verb 只能尽力执行；验收时需在目标 Windows 环境确认。
- 工作 Session 删除 API 仍在内部存在，UI 禁用依赖调用侧约束；后续可考虑收窄公开面，但不要在无迁移评估时贸然删除。
