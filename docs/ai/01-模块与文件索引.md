## 2. `DiaryOfMine.Domain`

该层不依赖 UI 和存储。修改字段或验证规则时，必须同时检查 JSON 反序列化兼容性、编辑窗口和 Application Service。

| 文件 | 主要内容 |
| --- | --- |
| `CalendarItemKind.cs` | `Class`、`Key`、`Idea`、`Inspiration` 四种枚举。Task 不在枚举内。 |
| `CalendarItem.cs` | 日程统一记录；验证 ID、标题、时间、颜色槽、Class/Key/Idea 完成状态、Key 三字概述、Task 批次归属与快捷链接集合。 |
| `CalendarFileLink.cs` | Class/Key/Idea 绑定的本地文件或文件夹地址、显示名、目录标记、单一置顶状态和添加时间；不保存其内容。 |
| `KeyTaskBatchInfo.cs` | 批次 ID、起止日期、星期位图、当天起止分钟。 |
| `DiaryEntry.cs` | 每日期一篇日记：标题、Base64 文档包、预览、搜索文本和时间戳。 |
| `WorkModeState.cs` | `WorkGoal`、`WorkSession`、`WorkInterruption`、聚合状态及验证。 |
| `ScheduleItem.cs` | 早期/通用日程模型；当前主要日程 UI 使用 `CalendarItem`，修改前先确认是否仍有调用。 |

## 4. `DiaryOfMine.Infrastructure`

| 文件 | 职责与注意点 |
| --- | --- |
| `Storage/LocalDataPaths.cs` | Debug/Release 数据根目录及设置、缓存、日志、旧 vault 路径。 |
| `Storage/PortableJsonUserDataRepository.cs` | 当前日程 JSON；范围查询、Task 批次、原子写入、缓存目录切换、旧 DPAPI 数据迁移。 |
| `Storage/PortableJsonDiaryRepository.cs` | 当前日记 JSON；按日期唯一、倒序读取、原子写入和目录切换。 |
| `Storage/PortableJsonWorkModeRepository.cs` | 当前工作模式 JSON；聚合状态原子写入和目录切换。 |
| `Storage/EncryptedJsonCalendarRepository.cs` | 旧 `calendar.dat` 的 Windows DPAPI 读写，仅作为兼容迁移源。 |
| `Storage/ReminderAcknowledgementStore.cs` | 已确认提醒的本地记录和过期裁剪。 |
| `Configuration/JsonAppSettingsStore.cs` | 创建默认设置、校验绝对路径/颜色/热键、保存 `appsettings.json`。 |
| `Logging/FileAppLogger.cs` | 按行写操作事件、结果、耗时和异常信息；支持运行时切换日志目录。 |

三个 Portable 仓储都用 `SemaphoreSlim` 串行化进程内访问，并用“同目录临时文件 + FlushToDisk + Replace/Move”提交。不要把它们替换为直接覆盖写入。

## 5. `DiaryOfMine.Desktop`

### 5.1 应用装配与导航

| 文件 | 职责 |
| --- | --- |
| `App.xaml.cs` | 全局组合根、单实例、`--startup`/`--unregister`、服务构造、窗口唯一性、跨视图刷新、缓存切换、退出保存。 |
| `App.xaml` | 全局资源与控件样式。 |

## 6. 典型调用链

### 新建普通日程

```text
HomePageView / FloatingWindow
  -> MainWindow 创建事件
  -> App.ShowCalendarEditor
  -> CalendarItemEditorWindow.TryCommitDraft
  -> HomePageViewModel.CreateAsync
  -> CalendarService.CreateAsync
  -> PortableJsonUserDataRepository.SaveAsync
  -> CalendarChanged / 提醒重排 / UI 重绘
```

### 打开并保存日记

```text
LinksPageView 或 单日详情“+日记”
  -> App.ShowDiaryEditorAsync（同一时刻只保留一个编辑器）
  -> DiaryEditorWindow 生成 FlowDocument package
  -> DiaryService.SaveAsync
  -> PortableJsonDiaryRepository.SaveAsync
  -> LinksPageViewModel.RefreshAsync
```

### 工作录制

```text
WorkModePageView 或 FloatingWindow 工作面板
  -> WorkModePageViewModel.StartAsync / FinishAsync / ToggleInterruptAsync
  -> WorkModeService 校验唯一活动记录与 24h 上限
  -> PortableJsonWorkModeRepository.SaveAsync
  -> VisualsChanged
  -> 页面、统计和悬浮窗录制状态同步
```
