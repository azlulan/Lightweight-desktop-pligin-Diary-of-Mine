# 界面交互与窗口生命周期

> 维护提示：未来修改功能时候，更新此处详细信息。

- 最后核对日期：2026-09-14

## 1. 主壳与页面

`MainWindow` 承载左侧导航和当前页面。`ShellViewModel` 从 `NavigationRegistry` 创建：日程表、日记、工作模式三个主页面，设置位于底部。页面实例按注册工厂延迟创建并复用。

`App.xaml.cs` 负责跨页面协调，不要在页面间直接互相持有：

- 主月历发出创建、编辑和打开单日详情事件，由 App 创建唯一编辑器/详情窗。
- 单日详情保存后触发 `DataChanged`，App 刷新月历并重排提醒。
- 详情“+日记”先提交/关闭详情，再导航日记并打开指定日期编辑器。
- 设置变更同步到窗口协调器、提醒、月历、详情和工作模式。

## 2. 主界面月历

入口：`Views/HomePageView.xaml(.cs)` + `ViewModels/HomePageViewModel.cs`。

### 布局和显示

- 始终绘制 6 周 × 7 天，查询区间与网格一致。
- 顶部支持上一/下一月、上一/下一年和“转到今天”；转到今天后自动选中当天方格。
- Class 以跨日条带绘制；信息通常显示在真实起始日，用户单击某日后，该日涉及的 Class 信息移动到该日段起点。
- 普通 Key 在日格左侧列，默认隐藏文字只保留色块；选中日期后显示文字。
- Task 生成的 Key 在同日日格右侧独立列，绘制、优先级和 Key 相同。
- Idea 通过日期悬停/弹层显示，可勾选完成。
- Class 剩余时间：当前时间未到起点时显示 `结束 - 开始`；进行中显示 `结束 - 当前时间`。拖动边界后必须重算显示和排序。
- 完成的 Class 和 Key 排在各自未完成项之后；Class 条带和 Key 色球改为浅灰色，名称/概述增加删除线，完成 Class 不创建倒计时文本。

### 输入和编辑

- 单击日期：选择/高亮，并展开该日 Class/Key 信息。
- `Shift + 左键` 点击 Class 条带或 Key 色球：立即切换该单条记录的完成状态，优先于端点拖动、甩飞和双击判断。
- 双击 Class/Key：普通项进入普通编辑器；Task occurrence 进入整个批次编辑器。
- 只有按下色块真实起止手柄才编辑边界；主月历边界吸附半小时。
- 从色块内部按下并明显甩出有效表面触发删除；普通/Task occurrence 都只删除当前记录。
- `Shift + 滚轮` 轮换同一区域的隐藏项目；上下提示随偏移更新，不能叠加残留旧 `+N` 标记。
- 月历自己的 undo/redo 记录 CRUD、边界和批次 before/after，不与单日详情共享。

## 3. 单日详细日程

入口：`Views/CalendarDayDetailWindow.xaml(.cs)` + `ViewModels/CalendarDayDetailViewModel.cs`。

### 唯一窗口与日期复用

应用只允许一个详情窗口。再次打开其他日期或点击前一天/后一天时调用 `NavigateToAsync` 复用现有窗口；切换前必须提交合法的正在编辑内容。窗口关闭后 App 恢复主窗口，不应把“回到月历”误处理为切换到程序外或最小化。

### 时间轴

- 一条逻辑 00:00—24:00 轴。可见宽度足以按至少 46 px/h 显示全日时用一行，否则自动折为两行；这是视觉折行，不是两条独立时间轴。
- 默认 62 px/h，滚轮缩放到最高 124 px/h；放大后可只显示全天的一部分，`VisibleMinutes = 1440 * 62 / 当前倍率`。
- 时间刻度每 30 分钟有网格线；标签间隔根据标签宽度和当前像素密度在 30/60/120/180/240/360/720/1440 分钟间自适应，避免 23:30 与 24:00 等重叠。
- 中键拖动画布；中键点击且未形成拖动时恢复默认倍率。缩放围绕鼠标指向的分钟保持位置。
- 今天显示柔和紫色当前时间线；其他日期不显示。
- 初次打开今天定位当前时间附近；其他日期定位第一项附近，仍可平移到完整一天。

### Class/Key 共享排列

- Class 与 Key 共用时间轴、并发检测、lane 容量和同一个 `Shift + 滚轮` 偏移。
- 可展示数量不是固定 5+5，而由窗口剩余高度和缩放后的 lane 高度动态计算；二者共同竞争容量。
- 优先级：当天结束的 Class -> 更早开始的 Key -> 当天不结束的 Class。多个同组 Class 按截止/优先时间和创建时间稳定排序。
- `IsCompleted` 是优先级的最外层规则：完成的 Class/Key 使用 `int.MaxValue` 优先组，始终在所有未完成项目之后。
- 隐藏项提示按重叠区间生成；上方/下方提示必须依据当前偏移实时重建，窗口尺寸和缩放变化后不得残留旧视觉。
- 鼠标在时间轴左侧主区域内即可 `Shift + 滚轮` 轮换附近并发项，不要求精确命中色块或狭窄区间。

### 色块文本和编辑

- Key 文本前加 `*`，与 Class 区分。
- 完成的 Class/Key 色块使用统一浅灰色；仅名称增加删除线，完整起止时间仍正常显示。
- 折行片段显示整个事项真实起止时间，不把分段行首误当作事项开始时间。
- 一个事项跨视觉行时，名称只在第一次渲染的片段显示；后续片段不重复名称。
- 默认文本布局稳定；悬停任一片段时，名称显示到该行此事项片段的最左起点。
- 真实起点/终点才显示边界手柄；跨日 Class 的中间日不显示伪手柄。
- 详情边界拖动精确到分钟；Task occurrence 的单次边界变更只影响当天记录。
- `Shift + 左键` 点击任意 Class/Key 色块可快捷切换当前记录的完成状态；Task Key 也只保存当前 occurrence，不调用批次替换。
- 双击编辑；色块内部拖动可甩飞删除。Idea 卡片也支持灵敏甩飞；灵感卡片保留同类编辑/删除语义。
- 详情有独立 undo/redo。切到相邻日期后仍可撤回刚才其他日期上的操作；历史只存在当前详情 ViewModel 生命周期。
- 悬停 Class/Key 色块会显示快捷链接浮窗；点击文件名或文件夹名使用系统默认方式打开。链接行提供“置顶”和移除，不使用方向箭头；失效路径按文件/文件夹类型重新定位，缓存目录路径显示易失提醒。

### 右侧栏和工具栏

- 右侧 Idea 为单列便签，支持勾选、双击编辑、甩飞删除。
- 悬停 Idea 便签使用与时间轴相同的快捷链接浮窗；Inspiration 不参与文件绑定。
- 灵感位于独立视口，通过“+灵感”录入；不选择日期，卡片右下显示创建时间。
- “+日记”打开当前详情日期的日记。
- 顶部日期标题左右排列前/后一天；“今天”位于右侧工具栏。工具栏包含创建 Class/Key/Idea/Task、撤销/重做、回到月历等现行操作。
- 热键提示需同时说明：滚轮缩放、中键拖动、中键单击恢复、Shift+左键切换完成、Shift+滚轮查看隐藏项、Esc 关闭。

## 4. 编辑窗口规则

### 普通事项编辑器

`CalendarItemEditorWindow` 负责 Class/Key/Idea/Inspiration：

- Class/Key 时间既支持选择器，也支持直接键盘输入，保存时统一验证。
- Class、Key 与 Idea 在相同位置显示“已经完成”复选框；Inspiration 不支持完成状态。
- Key 结束留空走 Application Service 默认 2 小时规则；不可跨午夜。
- Key 的三字概述旁有快捷按钮，可复制名称前三个文本元素。
- Key 概述允许留空输入；确认时自动按 Unicode 文本元素取名称前三个字并写入概述。Task 编辑器遵循同一规则。
- 默认颜色来自创建时随机逻辑槽位，显示时再按设置动态解析。
- 点击取消或 Esc 应无条件关闭且不保存，即使当前输入非法；不能用“非法输入”阻止取消。
- Class/Key/Idea 编辑器在保持原默认高度的同时向右扩展虚线圆角绑定区；支持从资源管理器混合拖入多个文件/文件夹，也可分别多选添加。每行名称负责打开，并提供“置顶”、移除及失效时的“重新定位”。只保存地址，不复制内容；Inspiration 保持原窄窗口且不显示绑定区。
- 普通单行输入、日期、时间和复选项按 Enter 依表单顺序前进，跳过隐藏或禁用项；到最后一个有效输入项时直接执行确认。灵感等多行输入保留 Enter 换行，Ctrl+Enter 执行确认。
- 默认窗口应让主要表单与底部确认区同时可见：普通日程约 `900×720`，Inspiration 约 `620×620`。

### Task 编辑器

`KeyTaskEditorWindow` 参考 Key 风格，额外支持日期范围、多个星期、分钟起止；新建生成多条 occurrence，编辑替换整批。Enter 从名称、概述、日期、星期选项和时间依次推进，最后确认；默认约 `700×780`，确认区应直接可见。

### 伴随窗口通则

- 创建 Class、Key、Idea/灵感、Task 等弹窗以 Owner 屏幕的工作区正中显示。
- Esc 关闭/取消当前子窗口；如果是日记等自动保存窗口，则先保存再关闭。
- 当用户点击主窗口时：详情和日记尝试保存后关闭；普通/Task 编辑器仅在输入合法时自动提交，非法内容不会保存且编辑器保持激活。编辑器自己的“取消/Esc”仍直接丢弃并关闭。

## 5. 日记

入口：`Views/LinksPageView.xaml(.cs)`、`LinksPageViewModel.cs`、`DiaryEditorWindow.xaml(.cs)`。

- 日记主页用自适应 Wrap 布局按日期倒序排列纸张卡片，标题格式由日期与用户标题组成。
- 顶部搜索区保留可点击宽度，按空白拆分多个 token；标题、正文 `SearchText` 和日期数字都参与匹配。
- “写今日日记”打开今天；详情“+日记”打开详情日期。每日期只保存一篇。
- 编辑器顶部标题、下方正文；图片作为单独 Block 插入，不环绕文字且图片之间不重叠。
- 支持复制粘贴文本/图片、插入图片文件、手动保存和“保存并退出”。
- “删除整篇”仅在当天已有持久化日记时可用，二次确认后删除当天标题、正文和内嵌图片；成功后关闭编辑器并刷新日记列表与月历日期标记。
- 删除二次确认及后续错误提示期间必须持有 `SuspendAutoFloat()` 作用域；作用域释放采用短暂激活宽限期并再次检查真实窗口状态。取消时恢复编辑器焦点，确认删除并关闭后恢复主窗口焦点，避免原生确认框的失活/激活消息延迟被误判为点击程序外部。
- “当日日程”先保存当前编辑内容，再关闭日记编辑器并复用该日期的唯一单日详情窗口。
- Esc、标题栏退出、程序退出都会尝试自动保存；保存失败应取消关闭并留在编辑器中。
- 日记编辑器不接入通用 Enter 确认/推进规则；正文 Enter 始终正常换行。仍只使用 Ctrl+S 快速保存、Esc 自动保存并退出。

## 6. 工作模式

入口：`Views/WorkModePageView.xaml(.cs)` + `WorkModePageViewModel.cs`。

- 时间轴固定为上下两行：00:00—12:00、12:00—24:00；只有一条工作录制 lane。
- 滚轮缩放整张图，中键拖动；中键点击恢复默认倍率。时间标签精度随宽度/缩放适配。
- 日期标题两侧切换日期，日历图标打开精确日期选择；不保留“选择日期”文字方框。
- 右侧按钮：`Add` 管理目标（不选颜色）、`Interrupt`、`Transcribe`、`Finish`，方框按钮统一圆角。
- Transcribe 弹层选择默认或用户目标后，从当前分钟开始录制；活动时显示“录制中”，中断时显示“录制中 · 中断标记中”。
- 不暂停。Finish 结束录制。录制可跨午夜但最大 24 小时。
- 活动录制时 Interrupt 开始/结束浅红中断层；无录制时打开编辑器，在已有已结束 Session 内创建中断。
- 手工中断编辑窗默认使用更充足的高度；表单区域可独立滚动，校验消息和“取消 / 添加中断”固定在底部，窗口缩小时仍应直接可见。
- 双击录制色块可更换工作目标。目标面板必须等第二次鼠标抬起后再打开，避免 `Popup.StaysOpen=False` 把同一次抬起判为外部点击；面板使用色块内实际点击点作为定位锚点，不能固定在远处工具栏。删除录制色块功能关闭，不应添加甩飞或删除菜单。
- 右下统计支持“今日/累计”和“时长/名称”排序，按目标聚合直方条；今日统计会裁剪跨日区间。
- 工作颜色只在设置“工作模式色板”修改，Add 不提供颜色选择。
- Add 目标管理窗与手工中断窗默认放大并固定显示底部操作区；目标名称按 Enter 添加/保存，中断表单按 Enter 顺序推进并在结束时间后确认。Transcribe 或双击色块打开目标面板后自动聚焦第一项目标，可直接按 Enter 选择；主工具栏按钮保留 WPF 原生 Enter 激活。

## 7. 悬浮窗、托盘和 Esc

入口：`WindowBehaviorCoordinator` + `FloatingWindow` + `TrayService`。

- 悬浮窗延续原紧凑排版（约 326 × 58），不应重做成普通工具条或多个新窗口。
- 按钮从左到右为：日程表、工作录制、设置、展开；设置图标视觉占比与前两项相当。
- 日程按钮弹出原风格图标面板，顺序固定 `Class -> Key -> Idea -> Task`，不能改成纯文字列表。
- 工作按钮弹出可滚动目标面板，不创建新窗口；选择目标与主工作页 Transcribe 相同，录制中显示相应状态。
- 设置直接恢复主界面并导航设置；展开恢复此前可编辑的主窗口/子窗口集合。
- 配置开启时，主窗口失焦切换到其他程序、最小化或关闭均进入悬浮休眠；`--startup` 与主窗口 Esc 仍是明确的悬浮入口。
- Class/Key/Task/Idea、日记、详情和工作编辑窗注册为自动悬浮保护窗口：存在时切换资源管理器或打开文件弹窗不进入悬浮，误触主窗口最小化/关闭时恢复编辑窗口。
- 应用内部原生弹窗通过前台进程识别或 `SuspendAutoFloat` 暂停作用域保护；提醒窗不属于编辑保护窗口，进入悬浮后仍可显示。
- 点击主窗口或其他程序不会自动提交、关闭或隐藏受保护编辑窗口，内容只由窗口内的确认、取消和关闭流程处理。
- Esc 在子窗口中先取消/关闭；主窗口再按 Esc 进入悬浮模式。全局 `ExpandHotKey` 在悬浮状态恢复主界面。
- 配置关闭时，最小化保留任务栏入口，关闭按钮隐藏到托盘但不退出进程；托盘和悬浮窗展开均恢复此前隐藏的窗口集合。

## 8. 提醒

- 日程变化、设置变化和启动后都会调用 `RescheduleRemindersAsync`。
- Scheduler 读取日程、调用 `ReminderPlanner`、跳过所有已完成事项和已确认项并设置下一次计时。
- Presentation 根据主窗口/悬浮窗和 ActivityState 选择位置与可见性；确认写入 acknowledgement store。
- 新增日程 Kind 时必须同步决定是否参与提醒、设置是否需要子开关、提醒 key 如何稳定生成。
